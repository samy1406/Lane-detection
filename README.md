# 🛣️ Lane Detection using Computer Vision

A computer vision project that detects road lanes in real-time using Python and OpenCV.

## 📁 Project Structure
├── lane_detection.ipynb   # Main notebook
├── input_video.mp4        # Input road video
├── output_video.mp4       # Processed output video
└── README.md

## 🛠️ Tech Stack
- Python
- OpenCV
- NumPy
- Google Colab

## 🚀 How to Run
1. Open `lane_detection.ipynb` in Google Colab
2. Upload your input video
3. Run all cells
4. Download the output video

## 📽️ Demo
Input → [Lane Detection Algorithm] → Output with detected lanes
